A.Furniture Furniture Factory Website

Temporary demo website for showcasing furniture products and directing customers to WhatsApp.

Files:
- index.html: Homepage
- product.html: Dynamic product detail page
- style.css: Website styling and responsive design
- script.js: Slider, mobile menu, active navigation, gallery lightbox, reveal animations and interactions
- images/: Local website images and A.Furniture logo

Temporary information such as phone number, email, social links and product prices can be replaced later with the real business details.

No backend is required for the current demo.
